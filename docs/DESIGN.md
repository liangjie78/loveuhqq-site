# 温柔信笺

首页是一张公开可访问的恋爱纪念信笺。设计以用户确认的样板图为依据：暖白纸纹、深棕宋体、少量旧玫瑰色与角落的信封线稿，重点是文字、留白和相恋时间。

## 内容与层级

由上到下依次呈现小字 `loveuhqq`、主标题“爱你，何青青。”、正文“把平凡的日子，慢慢写成我们的故事。”、相恋第几天，以及“始于 2026.07.01”。只使用已确认的称呼、日期和文案。

日期的唯一来源是 `src/lib/anniversary.ts`。2026-07-01 为第 1 天，按北京时间日历日期计数，在浏览器打开、跨日和重新回到前台时刷新。静态 HTML 保留真实起始日期，不把构建当天的天数写死；JavaScript 不可用时仍可阅读正文和日期。

## 视觉与布局

- 固定浅色：纸底 `--paper: #f8f3eb`，正文 `--ink: #493b35`，辅助文字 `--muted: #796a60`，数字点缀 `--rose: #a46b76`，信封 `--envelope: #b77984`。系统深色偏好不改变本页的信笺色调。
- 中文采用本机 `Songti SC / STSong / SimSun / serif`；英文署名、天数与日期使用 `Georgia / Times New Roman / serif`，不请求外部字体。
- 画面单列居中，包含角落装饰的整体最大宽度为 56rem，文字内容最大宽度为 40rem，两侧留白至少 1.5rem。标题最大 5.5rem，正文最大 1.3125rem，日期 0.9375rem。
- 600px 及以下采用双行标题，在逗号后换行；正文也按两句排列。手机标题为 2.75–3.75rem，正文 1.0625rem。小屏、横屏和文字放大时自然滚动，不固定页面高度或隐藏溢出。
- 相恋数字使用等宽数字字形，预留显示区域。纸纹来自内嵌 SVG，信封为装饰性内联 SVG，不使用照片、位图背景、组件库或第三方素材请求。

## 动效与可读性

- 署名、标题、正文、纪念信息、信封按顺序淡入，各段 520ms、间隔 120ms，约 1 秒内完成；不循环，不改变几何尺寸。
- `prefers-reduced-motion: reduce` 下取消动效，所有内容直接可见；动画不承担任何功能状态。
- 保持中文 `lang`、viewport、唯一主标题与语义化 `time`。信封不参与辅助技术读取、不接收焦点，不呈现虚假的点击动作。

页面和样式分别位于 `src/pages/index.astro` 与 `src/styles/global.css`。日期计算由 Node 内置测试覆盖，实际排版和动效须以浏览器检查为准。
