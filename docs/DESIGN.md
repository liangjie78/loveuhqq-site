# 温柔信笺纪念册

V2 首页以用户确认的桌面、手机样板为依据：暖白纸纹、深棕宋体、旧玫瑰色、拍立得与蜡封信笺。首页从一张纪念信笺扩展为可以逐步填入真实回忆的单页纪念册，保持克制和留白。

## 内容

- 顶部导航跳转到首页、故事、照片、纪念日、未来；手机端展开菜单，选中链接或按 Escape 收起。
- 首屏保留“爱你，何青青。”、“把平凡的日子，慢慢写成我们的故事。”与确认的起始日期。
- 故事时间轴只有已确认的起始日。照片位置与后续故事留空，不编造其他经历、地点或日期。
- 相册使用三张 AI 生成的风景、静物示意照片，每张标明“示意图片”；入口和大图继续说明示意性质。真实素材提供后再替换。
- “今天想对你说”暂用已确认的首页文案并标记待填写，不假装已有每日随机语录。
- 未来信标记“信件待写”，只展示对应纪念日，不提供虚假解锁或已写信件内容。
- 页尾“未完待续……”与边注沿用确认的样板；不增加未经确认的私人信息。

## 日期与状态

起始日期的唯一来源是 `src/lib/anniversary.ts`。2026-07-01 为第 1 天，按北京时间日历日期计数，在页面打开、跨午夜和重新回到前台时刷新。

第 100 天由起始日加 99 天推导；下一纪念日优先展示尚未过去的第 100 天，之后展示最近周年日，当日显示“今天”，次日转向下一个周年。未来信是固定的第 100 天主题，不随下一纪念日改变。

静态 HTML 只保留真实起始日期和可推导的固定纪念日，不写死构建当日的天数与倒计时。无 JavaScript 时使用“值得记住的日子”标题，保留正文、日期、导航和图片原图链接。

## 视觉与布局

- 固定浅色：纸底 `#f8f3eb`、正文 `#493b35`、辅助文字 `#796a60`、旧玫瑰 `#a46b76`、细线 `#d8c7bd`。系统深色偏好不改变信笺色调。
- 中文沿用本机 Songti SC / STSong / SimSun / serif，英文和数字使用 Georgia / Times New Roman / serif，不请求外部字体。
- 桌面内容宽度上限 76rem；时间轴、相册及结尾纪念日与未来信利用横向空间。手机端单列，每侧至少 1.5rem，隐藏边注。
- 手机首屏标题在逗号后换行；正文按两句排列。正常内容决定页面高度，不锁定页面或隐藏横向溢出来掩盖布局问题。
- 手机相册在自身区域横向滑动，页面本身不横向滚动。三张图片都可通过大图的前后按钮查看。
- 纸纹来自内嵌 SVG；三张示意照片及带透明背景的信封为本地 WebP，总计约 254 KiB。相册与页尾图片懒加载，指定固有尺寸以保留布局空间。

## 交互

相册使用原生 `dialog`，支持点击照片、翻开相册、前后按钮、左右方向键、Escape 与关闭按钮。关闭后焦点回到打开相册的位置；模态打开时锁定底层滚动，大图正文是弹窗内唯一滚动区。无 JavaScript 时照片链接直接打开本地图片。

淡入仅用于首屏；照片悬停轻微抬起。减少动态效果偏好下禁用动画、过渡和平滑滚动。装饰图片不参与辅助技术读取，不接收焦点。

## 修改位置

- `src/pages/index.astro`：内容和页面结构。
- `src/styles/global.css`：排版、响应式和动效。
- `src/scripts/keepsake.ts`：日期刷新、导航和相册。
- `src/data/photos.ts`、`public/images/`：相册数据与本地素材。
- `src/lib/anniversary.ts`、`tests/anniversary.test.mjs`：日期计算与边界测试。

实际排版、菜单、相册、跨日显示、无脚本回退须使用真实浏览器检查；单元测试不能替代视觉验收。
