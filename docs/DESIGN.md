# 余温 · 设计说明

整站像夜里为对方留着的一盏灯：每一天是一粒被点亮的光。温馨来自暖光、柔和颗粒和慢呼吸的节奏；极简来自大面积留白和单一强调色；高级感来自超大衬线字、精确网格和电影感的缓动。2026-10-28 起替代此前的“纸上手账”拟物风格（胶带、拍立得、邮戳、纸心图片全部移除），只保留用户数据与已确认文案。

本文件描述当前源码的设计约定，不代表生产网站已发布该版本；发布状态以部署记录和实际核验为准。

## 边界

- **保留不动（数据层）**：`worker/**`、`migrations/**`、`wrangler*.jsonc`、`public/_headers`（CSP 不变）、`scripts/*` 运维脚本、`src/lib/**`（类型、接口、校验、日期计算、协议）、`src/stores/**`、`src/data/moments.ts`。D1/KV/DO 的结构与接口均未改变，现有记录无需迁移。
- **全部新做（表现层）**：`src/layouts/Base.astro`、`src/components/**`、`src/pages/*`、`src/app/*`（原生 TypeScript 控制器）、`src/motion/*`（动效原语）、`src/styles/*`、`public/` 下的图标、清单与分享图。
- **文案**：只使用已确认的称呼、文案和日期，集中在 `src/content/copy.ts`；运行时提示语与使用它的控制器放在一起，均从旧版逐字迁移。不新增情话、经历、地点或私人信息。

## 技术形态

- Astro 静态生成；交互由 `src/app/*.ts` 原生控制器完成，不再使用 React、Tailwind、shadcn、radix 或 dnd-kit。依赖只剩 `astro`、`motion`、`lenis`、`lucide`、`zustand`。
- 会话与署名仍经 `src/lib/session.ts`、`src/lib/member.ts` 与两个 zustand store；跨标签同步（退出、署名切换、未保存草稿询问）沿用原协议，署名频道封装在 `src/lib/identity-channel.ts`。
- 从旧脚本抽出的纯逻辑：`notebook-sync.ts`（校验、按修订号合并、草稿、搜索、摘录）、`calendar-labels.ts`（年份、周年、读数）、`photo-upload.ts`（EXIF 日期、文件名标题、摘要、WebP 重编码、分栏）。
- 首页 JS 约 59KB（gzip），所有页面不加载任何外部资源。

## 视觉系统（`src/styles/tokens.css`）

- **颜色**：浅色「余温」底 `#f6f0e8`、抬升面 `#fbf7f2`、墨 `#1e1614`、次墨 `#5e4f48`、淡墨 `#7a6a61`（4.57:1，满足 AA）、唯一强调色胭脂 `#b23a48`（5.16:1）；光晕 `#f7b79a` / `#f0a0a8` / `#ffe6c7` 只作为光使用，不作文字底色。深色「夜灯」底 `#110d0c`、墨 `#f4eae0`、胭脂 `#e7838a`、光晕转为琥珀与玫瑰。照片章节与页脚在浅色模式下是“夜幕”章节（`.is-night` 局部换色板），形成明暗节奏。所有颜色只走令牌。
- **主题**：页眉开关切换，记忆在 `loveuhqq_theme`，默认浅色，不跟随系统；切换时用 View Transition 从开关处圆形铺开；`color-scheme` 与 `theme-color` 同步。
- **字体**：思源宋体可变字重子集（wght 300–500，约 196KB）用于标题与引文，可做字重呼吸；Instrument Serif（常规 + 意大利体，ASCII 子集各约 15KB）用于数字、日期、序号与字标；正文与界面用系统无衬线；私密正文与照片标题只用系统字体（字体子集是字符集“预言机”，不收录私密字）。`npm run subset:font` 重新生成，`tests/unit/fonts.test.mjs` 守护覆盖与隐私。
- **字号与留白**：九级流体字号 `--step--2…--step-7`；12 栏网格，页边 `clamp(1rem, 5.6vw, 5.5rem)`，最大宽度 90rem，章节上下留白 `clamp(7rem, 20vh, 15rem)`；手机侧边距 ≥16px，任何页面不出现横向滚动。正文 `text-wrap: pretty`、标题 `balance`，大字标题按视口宽度封顶并禁止断行，避免孤字。
- **质感**：全站 5% 动态胶片颗粒（`.grain`），精细指针设备上一团跟随指针的暖光（`.lamp`），取代纸纹与胶带。

## 动效语言（`src/motion/`）

- 缓动 expo-out `cubic-bezier(.16,1,.3,1)`、in-out `cubic-bezier(.65,0,.35,1)`；时长 180 / 420 / 900 / 1600ms 四档。只动 transform、opacity、filter。
- **余温光晕**（`aura.ts`）：手写 WebGL 片元着色器，域扭曲噪声生成一团慢呼吸的暖光，缓慢倾向指针；封面亮度随在一起的天数微微增加。半分辨率渲染、离屏与后台暂停；无 WebGL 时退回 CSS 渐变。封面、门禁、回忆册封面、页脚、404 共用。
- **显影**：章节标题逐字由模糊到清晰（`split.ts` + `reveal.ts`，保留一份纯文本给读屏）；区块淡入上浮。
- **一天一粒光**：年历每天一颗光点，首次进入视口时像一串灯依次点亮（约 1 秒），今天在呼吸，第 100 天与周年日是心形，悬停时当前与相邻格鱼眼放大。
- **滚轮数字**（`odometer.ts`）：天数、已涂格数、纪念日倒计时。
- **心里话逐字点亮**：章节吸顶，随滚动把字从淡墨逐个读亮，最后浮出落款。
- **门禁光绽**：答对后光从输入处扩散铺满屏幕，再溶解进首页；答错时数字格轻摇。
- **拆信**：蜡封放大淡出、封盖 3D 翻开、信纸上升，再进入阅读弹窗，段落依次浮现。
- **其他**：按钮的墨色从指针进入处涌起，部分按钮磁吸；导航胶囊的当前指示器滑动；桌面端 Lenis 平滑滚动（门禁、弹窗、菜单打开时暂停）；跨页 View Transition 淡入淡出；页眉向下阅读时收起、回看时出现，压在夜幕章节上自动换色。
- `prefers-reduced-motion`：所有过渡、动画与延迟归零，关闭 Lenis、跟随光和光晕动画（光晕保留静帧），逐字点亮改为直接全亮，门禁直接解锁。

## 页面

- **页眉**：左字标（Instrument Serif 意大利体 + 心跳红点），中部毛玻璃胶囊导航（首页五章：日子 照片 心里话 往后 信；回忆册六章），右侧第 N 天小签、主题开关、会话（访客 / 署名弹层 / 退出），子页有“回到日记”。≤64rem 时导航收进全屏菜单，大号衬线链接错峰进场；≤48rem 时子页会话说明隐藏、回到日记只留图标。
- **首页** `/`：封面（巨大题字「爱你，／何青青。」、单笔心形、光晕、底部计数栏）→ 日子（吸顶标题与两项滚轮统计，光点年历、读数、往年翻看、日子的背面，记下的日子时间线）→ 照片（夜幕章节，三张编辑式错落照片，锁定时三块流光空框）→ 心里话（吸顶逐字点亮）→ 往后（清单与“抽一件”洗牌）→ 共同回忆册入口（六行目录，悬停整行展开、字重变化）→ 信（蜡封信封与“待拆／可拆”印）→ 页脚（夜幕，「往后。未完待续。」与光晕余辉）。
- **相册** `/photos/`：巨大标题与张数，照片按高度平衡分栏（1/2/3 栏），自下而上擦入；灯箱从缩略图放大进入，支持方向键、滑动、Esc，关闭后焦点回到原照片；“贴一张”支持点选与拖放；改标题、设为首页精选（最多三张）、取下。
- **回忆册** `/memories/`：封面（标题、署名、导出、目录）+ 六章（故事、往后与后来、未来邮局、回忆放映室、地点备忘、共同桌面），统一“序号 · 章名 · 说明 · 锁定卡 / 内容”结构；故事有手账、照片手账、信纸三种排版；放映室是夜幕舞台，带推镜与进度线；地点按时间轴排列；桌面支持指针拖动与方向键。
- **门禁**：全屏光晕，问题「我们，／是从哪天开始的？」，四位数字格（一个隐藏输入驱动），共同密码阶段，访客浏览与 Esc；退出未确认时只显示重试。
- **404**：描边大号 404、「这一页，好像被撕掉了。」与光晕。

## 行为约定（沿用）

日期以北京时间计，2026-07-01 为第 1 天；恋爱年份以周年日收尾；下一纪念日先指向第 100 天再指向周年；百日信自第 100 天起可读，正文只经服务端会话读取，关闭、退出、跨标签撤销、页面离开时清空。日记与清单按修订号合并、冲突时保留草稿并给出对照；草稿只存当前标签页。照片、信件、回忆册内容在退出与往返缓存恢复时清空。分享预览（description、OG 图）不包含起始日期——那正是门禁的答案。
