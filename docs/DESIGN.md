# 全屏纪念册

首页以六屏叙事呈现已确认的纪念内容：柔粉与淡紫渐变、系统无衬线字体、大标题、留白与毛玻璃。视觉参考为 [Apple iPhone Air](https://www.apple.com/iphone-air/) 和 [DJI Mavic 4 Pro](https://www.dji.com/cn/mavic-4-pro)，借鉴章节叙事、画面层级与连续滚动的节奏；章节之间不强制吸附。

本文件描述当前源码的设计约定，不代表生产网站已发布该版本；发布状态以部署记录和实际核验为准。

## 内容

- 六屏依次为首页、故事、照片、心里话、纪念日、未来。顶部导航与桌面侧边章节导航跳转到对应屏幕；页脚置于最后一屏内，提供回到首页的入口。
- 首屏保留“爱你，何青青。”、“把平凡的日子，慢慢写成我们的故事。”与确认的起始日期。
- 故事时间轴只有已确认的起始日。照片位置与后续故事留空，不编造其他经历、地点或日期。
- 首页相册暂时保留三张 AI 生成的风景、静物示意照片，每张标明“示意图片”；大图与独立的“更多照片”页继续说明示意性质。真实素材提供后再替换。
- “今天想对你说”只展示待填写状态，不重复首页文案或假装已有每日随机语录。
- 未来信标记“信件待写”，只展示对应纪念日，不提供虚假解锁或已写信件内容。
- 保留“未完待续……”及已确认的边注文案，按新布局安排位置；不增加未经确认的私人信息。

## 日期与状态

起始日期的唯一来源是 `src/lib/anniversary.ts`。2026-07-01 为第 1 天，按北京时间日历日期计数，在页面打开、跨午夜和重新回到前台时刷新。

第 100 天由起始日加 99 天推导；下一纪念日优先展示尚未过去的第 100 天，之后展示最近周年日，当日显示“今天”，次日转向下一个周年。未来信是固定的第 100 天主题，不随下一纪念日改变。

静态 HTML 只保留真实起始日期和可推导的固定纪念日，不写死构建当日的天数与倒计时。无 JavaScript 时保留“值得记住的日子”的静态标题、正文、日期、导航和图片原图链接。

## 视觉与布局

- 固定浅色：基础背景 `#fcfafb`、正文 `#302830`、辅助文字 `#776971`、玫瑰强调色 `#a34768`，各屏用柔粉、淡紫和近白色渐变区分。系统深色偏好不改变页面配色。
- 正文、标题和数字使用本机系统无衬线字体栈，包括 Segoe UI、PingFang SC、Microsoft YaHei；标识和装饰引号少量使用 Georgia，不请求外部字体。
- 固定页眉使用半透明背景与毛玻璃，首屏以一枚哑光、实心的纸质爱心呼应柔粉背景；计数卡片居中放在爱心正下方。计数和纪念日卡片使用轻边框、圆角与柔和阴影。装饰不遮挡正文或操作入口。
- 桌面主体内容宽度上限 76rem，首页、故事、纪念日和未来屏使用双栏；手机改为单列，每侧保留 1.5rem 内边距，省去侧边章节导航与次要边注。
- 首页标题在逗号后换行；普通桌面、手机竖屏和横屏均以每个章节占一视口为布局目标。短屏通过重新分配图文空间、收紧间距和缩小装饰适配，不裁切正文来制造单屏效果。
- 首页相册桌面显示三列，手机显示一张横向大卡与下方两张卡片，三张图片直接可见；不再建立相册横向滚动区。图片卡片裁切预览，大图保持原始比例。“点击进入更多照片”通向独立相册页，后续添加的图片由 `src/data/photos.ts` 统一提供。
- 三张示意照片、透明背景信封和纸质爱心使用本地 WebP；首屏爱心直接加载，其余图片懒加载，均声明固有尺寸，不引入远程图片或视频依赖。

## 滚动与响应式

文档根元素是页面唯一纵向滚动容器。六个 `.chapter` 保持章节叙事和视口高度，但不设置滚动吸附；滚轮、触屏和键盘沿用浏览器原生连续滚动，不用 JavaScript 拦截输入或模拟逐屏翻页。章节链接平滑跳转，减少动态效果偏好下立即跳转。

每屏以 `min-height: 100dvh` 适应移动浏览器动态地址栏，并保留 `100vh` 回退。屏内预留固定页眉和安全区的空间；正文与屏底提示由 Grid 分配高度，末屏页脚不额外形成一段页面。极小视口或文字放大导致内容超过可用高度时，以正文和操作仍可完整到达为底线，允许内容撑高；这不替代普通手机视口的单屏适配。

## 交互

导航通过可见章节更新 `aria-current="location"`，同步顶部选中状态与桌面侧边标记。手机端展开菜单，选中链接、点击页眉外部、焦点移出页眉、按 Escape 或跨越响应式断点时收起；Escape 将焦点返回菜单按钮。无 JavaScript 时直接展示导航链接。

首页相册使用原生 `dialog`，支持点击照片、翻开相册、循环前后切换、左右方向键、Escape、关闭按钮和点击遮罩关闭。关闭后焦点回到打开相册的位置，避免主动滚动跳位；模态打开时锁定文档根元素与 body，大图正文是弹窗内唯一滚动区，标题和切换操作保持可达。无 JavaScript 时照片链接直接打开本地图片；修饰键点击保留浏览器原图打开行为。独立相册页展示全部图片，点击图片可打开原图；首页入口无 JavaScript 时仍可导航。

章节首次进入视口时使用短暂的轻微上移与淡入，照片悬停仅轻微放大；首屏爱心保持静态。减少动态效果偏好下禁用动画、过渡和平滑滚动，正文立即可见。动效是渐进增强，无脚本或缺少观察器支持时不隐藏正文。装饰图片不参与辅助技术读取，不接收焦点。

## 修改位置

- `src/pages/index.astro`：内容和页面结构。
- `src/pages/photos.astro`：独立相册页。
- `src/styles/global.css`：排版、响应式和动效。
- `src/scripts/keepsake.ts`：日期刷新、导航和相册。
- `src/data/photos.ts`、`public/images/`：相册数据与本地素材。
- `public/_headers`：静态资源的浏览器安全响应头。
- `src/lib/anniversary.ts`、`tests/anniversary.test.mjs`：日期计算与边界测试。

验收需实际构建，并使用真实浏览器检查六屏尺寸和连续滚动、锚点与选中状态、普通手机及短屏横屏布局、菜单、相册锁滚动与焦点返回、跨日显示、无脚本回退和减少动态效果偏好。单元测试不能替代视觉与输入行为验收；验证结果单独记录，不由本设计约定推定通过。
