# 基础视觉方向

当前仅是占位首页，尚未形成完整品牌系统；后续设计可以调整。

- 简洁、干净、温柔，仅保留站名和两句中文说明。无照片、真实姓名、纪念日、背景音乐或第三方素材。
- 布局：单列居中，内容最大宽度 38rem；页面两侧留白 1.5rem，适配手机和电脑。
- 正文使用系统字体，站名使用 Georgia / Times New Roman / serif；正文 1.125rem，次要说明 0.9375rem，行高 1.9。
- 浅色背景 `#faf7f8`、正文 `#30272d`、次要文字 `#77616e`、点缀 `#a43f68`。
- 系统深色偏好下背景 `#191519`、正文 `#f4eaf0`、次要文字 `#bba6b3`、点缀 `#e79bbb`。
- 不引入动画、组件库或复杂页面架构。图标为基础字母标识，非完整品牌标志。
- 样式来源：`src/styles/global.css`；页面来源：`src/pages/index.astro`。保持语义 HTML、中文 lang 和 viewport，缩放时不遮挡文字。
