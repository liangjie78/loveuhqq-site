# 纸上手账

整站是一本摊开的手账：暖色纸面、蜡封红、宋体字，内容像是用胶带贴上去的实物——纸做的心、拍立得、信纸、信封和邮戳。页面继续自然连续滚动；2026-10-21 用户要求导航使用吸顶半透明毛玻璃，并加入可记忆的深色模式、InputOTP 分格门禁、门禁盖章解锁和更明显的错落照片墙。毛玻璃只用于导航，不改变纸面主体的手账质感。

本文件描述当前源码的设计约定，不代表生产网站已发布该版本；发布状态以部署记录和实际核验为准。

## 实现方式

- 继续由 Astro 静态生成页面，公开内容保留在 HTML。React 客户端岛屿用于页眉会话、首页署名、门禁 InputOTP 和回忆册共同桌面；会话与署名先以访客状态服务端渲染，私密桌面只在登录并选好身份后创建。
- 组件源码采用 shadcn/ui Nova，保存在 `src/components/ui/`；暖纸色、蜡封红与宋体由全局样式提供，浅色纸面默认显示，深色令牌在 `ui.css` 中定义并由页眉开关写入 `loveuhqq_theme`。Astro 和原生脚本使用组件变体共享按钮、输入类。
- 控制图标只使用 `lucide-react`。滚动入场、日历涂色、天数计数、纸心反馈和信封晃动使用 `motion`；减少动态效果时直接显示最终状态。纸心落下、标题落墨和视差继续由现有 CSS 负责。
- 会话与当前身份分别保存在 Zustand store。会话写入仍只经过 `src/lib/session.ts`；身份写入使用 `src/lib/member.ts` 的 `selectMember`。日记修订、照片、回忆册数据和桌面快照继续由现有请求与服务端协议管理。
- 共同桌面用 `@dnd-kit/core` 处理指针拖动，坐标夹取、消息顺序和冲突恢复保存在 `src/lib/desktop-client.ts`；年历、照片灯箱、长页分区和原生对话框继续使用现有实现。

## 内容

- 只使用已确认的称呼、文案和日期：“爱你，何青青。”“记录生活，慢慢往前走。”“平平淡淡，踏实过好每一天。”“往后。未完待续。”“往后的日子也想和你一起”（用户确认的“往后”标题），起始日 2026-07-01。界面上的说明性文字（按钮、提示、空状态）保持口语、克制，不写矫情情话，不编造经历、地点或私人信息。
- 首页自上而下：封面、日子、照片、心里话、往后、共同回忆册入口、信、页脚。自然连续滚动，不分屏、不吸附。
- 首页局部轻视差：封面纸心与标题错速移动，三张拍立得小幅错速，心里话只移动背后的叠纸（正文与胶带稳定），信封图片轻微浮动。保留淡入、倾斜及悬停反馈；日历、手账编辑器和往后清单不参与视差。视差使用原生 CSS 滚动时间线，桌面最大位移 44px，≤720px 时幅度降至 35%；区块入场等计时动作用 Motion，减少动态效果或浏览器不支持时保持静态。
- **封面**：两行横排大题字“爱你，/ 何青青。”，第二行以蜡封红错位缩进；右侧是斜放、贴着胶带的纸心和起始日期邮戳。下方由一条细线分出横向计数栏，将“今天，是我们在一起的”、第 N 天和起始日期排在同一行。
- **日子**：“一天，记一格。”每一天是一个格子，按月排成一行（手机上转为一月一列）。走过的日子涂上深浅不一的红，今天带一圈脉动描边，第 100 天和周年日是心形。下方统计“已经涂了 N 格”，随当前显示的年份变化；“下一个纪念日”倒计时始终从今天算起，是所有年份共用的一项“现在”。
- **回看往年**：日历默认显示今天所在的年份；进入第二年及以后，范围行下方出现“← 上一年 / 下一年 →”，可一直翻回第一年（第一年时整行收起），读数改成该年的起止日期，格子、“已经涂了 N 格”与 `aria-label` 一并切换，“回到今天”跳回当前年份。翻看往年不改动正在编辑的手账草稿。
- **照片墙**：三张拍立得，用胶带贴在纸上，微微倾斜。照片是私密的：访客只看到三张虚线“待解锁”空位和“解锁照片”入口；解锁后从 Worker 取回 `featured` 精选照片（有则最多三张；`featured` 为空时首页保持占位、不回退为相册前几张），标题是用户给的备注、角上是拍摄日期。访客点“翻开整本相册”会先打开门禁，解锁后再进入 `/photos/`；进出相册时使用轻微淡入淡出，减少动态效果或浏览器不支持时直接跳转。
- **心里话**：一张横线信纸，背后错位叠着一层纸，顶部贴着胶带；左侧红色页边线和打孔，文字压在横线上。“心里话”在桌面作为纸外竖排章名，手机移到信纸上方；落款按完整短句换行，避免小屏出现孤立的字。
- **信**：“写给第 100 天”。公开信封旁显示“待拆”印章和倒计时；北京时间 2026-10-08 00:00 起显示“可拆”。访客点击进入共同密码解锁，解锁后且日期已到时继续拆信。正文按需从服务端取得，在原生纸信弹窗中只读展示，使用已确认初稿。正文使用系统字体，宋体标题、纸面与蜡封红沿用整站风格。提供加载、错误重试与收信反馈，支持关闭按钮、Esc 和遮罩关闭，关闭后焦点回到信封。手机长文只在正文区滚动，标题与关闭入口保持可见。
- **相册页**：访客看到“解锁后，才能翻开这本相册。”和虚线空位；解锁后全部照片按拍摄日期排成拍立得墙（无日期的排在最后），末尾可点“贴一张”（辅文案“留给下一张”）在站内追加一张去 EXIF 的 WebP；新图不自动进首页精选。退出、跨标签撤销会话或页面进入往返缓存时立即清空照片、关闭贴图面板并恢复空位。
- **日子的背面**：日历下的一张折角纸签，随选择显示日期；解锁共同手账后才加载私密正文、索引和编辑入口。主动点击“写一句”后才出现横线编辑器。记录保存在 D1，支持修改、移除与撤销、按日期翻看；写过的格子带墨色描边。编辑期间保留正在写的日期，不因悬停、跨日或远端更新切换草稿。
- **写作灵感**：解锁后的“日子的背面”内，日期标题下放置带蜡封红手绘小花的提问行，“换个话头”依次翻看九个适用于所选日期的日常提问，使用轻微落墨反馈。整张卡只保留一个“写一句／改一改”入口，提问只提供灵感，不自动填入正文，也不切换日期。初次打开手账默认显示北京时间今天；正在编辑时换话头仍保留日期与输入。
- **回忆书签**：解锁后的日记下方提供“随手翻一页”，从已保存的非空日记里随机回看，有多篇时不连续打开同一天；没有记录时说明写下第一句后即可翻页。展开“翻看写过的日子”后，可按日期（月日或完整日期）和正文关键词查找，列表分别展示日期与短摘录。搜索只使用当前会话内已加载的手账，退出即清空搜索、日期与摘录，不写入 URL 或存储；翻页复用现有草稿保护，不自动修改或保存记录。
- **记下的日子**：以打孔票根展示已确认的故事日期和第一天，包括早于日历起点的记录。未来日期标注“还没到”，仅在当天显示“时候已到”，过后不显示标签。
- **往后**：左侧标题“往后的日子也想和你一起”、右侧贴着胶带的横线清单；手机上下排列。访客显示“解锁后，翻看我们的记录”；解锁后加载共同清单，支持新增、修改、完成、移除与撤销，也可以从未完成事项里抽一件。
- **共同回忆册入口**：位于“往后”与“信”之间（愿望变成故事，再通往未来邮局和第一封百日信）。桌面左侧是贴着胶带、略微倾斜的目录页，右侧是标题、一句说明和“翻开共同回忆册”按钮，和上一章交换视觉重心；手机先显示介绍，再显示目录。六个分区用点线连到各自的说明，上下留白比普通区块收紧，与下方的信连成一段。文案全部沿用 `/memories/` 页自己的标题与说明，不新增文字；只有静态外壳，不读取任何私密数据，访客与解锁后看到的相同。点目录项进入 `/memories/#分区`，页面在解锁后的内容显示出来时再滚到该分区（落点与页内导航一致），没有对应分区或 hash 无效时留在顶部。不增加页眉导航项：页眉仍是五个入口。窄于 380px 时目录改为上下两行。
- 首页保留“往后”导航；≤720px 时字标与导航分两行，保持五个入口完整可点，日历置顶读数沿用对应页眉高度。
- 日记与清单共用一份云端手账，服务器确认后才提示保存成功。页面可见时每 10 秒检查更新，回到前台立即刷新；同条记录以修订号检查冲突，保留输入并展示最新内容，不自动覆盖。草稿可暂存在本标签页的 sessionStorage，登录后恢复；访客不读取或显示草稿及旧本机记录，退出清空内存中的私密正文。页面不提供手动导入或导出，旧本机手账不删除。预览与生产使用独立数据库，真实记录只保存在生产数据库。无 JavaScript 时保留原有静态展示，私密记录不在 HTML 中。
- **404**：一张底边被撕开的纸，“这一页，好像被撕掉了。”

## 共同回忆册

`/memories/` 为独立的长卷纸面工作台，首页保持原有自然连续阅读与五个导航锚点，只在“往后”与“信”之间设一个入口区块。回忆册页每个小节（故事、往后与后来、未来邮局、放映室、地点及共同桌面）均重构为类似首页的独立满幅手账区块，并提供专属的顶部固定导航与滚动定位联动；未解锁时展现完整手账外壳与占位，解锁后展开私密交互。六个分区都成对使用锁卡与私有容器，共同桌面的控件只在该容器显示后才由脚本创建，访客不会看到无响应的输入框。窄于 768px 时页眉分两行：字标与“访客／回到日记”在上，六个分区导航占满第二行，`--header` 随之增高，分区留白与滚动落点沿用同一变量；更窄的 400px 以下再收小字号，保证两行放得下。回忆册和相册的“回到日记”都回到首页对应位置（`/#memories`、`/#photos`）。从日记日期、照片灯箱和愿望链接进入同一份故事集合；不会自动把旧日记变成故事。手机按内容自然纵向阅读。

共同密码后，首页上方选择男生或女生作为署名，不再设置个人口令。故事共同正文可一起整理，双方的版本单独编辑；共同揭晓时显示对方是否提交，未开放正文与声音由服务端过滤。编辑需要主动展开，冲突保留输入并给出最新内容对照，采用新版本后仍需明确再次保存。

故事提供手账、照片手账和信纸三种排法，私密正文使用系统字体。愿望安排日期与完成后的故事关联分开保存，取消完成不会取下故事或照片。未来信件以信封阅读卡呈现状态，封存后不可编辑、拆信日前可撤回，正文按收件人与北京时间日期开放；旧百日信入口保留。

录音先录制或选文件、试听，再上传并保存到所属段落或信件。放映只使用当前身份能够读取的已保存内容，可手动翻页、自动播放、暂停与重播；减少动态效果时手动翻页。地点当前采用轻量备忘：名称、年份与故事／愿望关联，坐标收在可选展开项中，留空也能保存；不加载外部底图、不读取定位。空状态不暗示已经共同到过某地。共同桌面支持照片、故事、便签和票根，以服务端保存回执为准，断线或同物件冲突时提供明确恢复选择。

退出、个人身份变化、会话失效和页面离开时清除正文、动态下拉选项、媒体、录音、对象 URL、放映和桌面连接。公开静态页面只有外壳与空状态。页面可见时的十秒刷新只重建内容真正变化的列表，未变化时保留原节点，避免键盘焦点丢失；首次加载后不再反复显示“正在翻开”提示。实现文件为 `src/pages/memories.astro`、`src/scripts/memory-book.ts`、`shared-desktop.ts`、`src/styles/memory-book.css` 和 `memory-tools.css`；服务端边界与发布步骤见部署文档。

## 日期与状态

起始日期的唯一来源是 `src/lib/anniversary.ts`。2026-07-01 为第 1 天，按北京时间日历日计数，在打开页面、跨午夜和回到前台时刷新。

- “恋爱年份”以周年日收尾：第一年从 2026-07-01 到 2027-07-01（共 366 格，末格是一周年），第二年从 2027-07-02 到 2028-07-01，以此类推。日子区块默认显示今天所在的年份，跨年后由脚本重建格子；跨年那一刻只把正在看当前年份的读者带去新年，正在回看旧年的人留在原处。
- 下一纪念日沿用原有规则：第 100 天之前指向第 100 天，之后指向最近的周年日，当天显示“就是今天”。
- 信固定为第 100 天主题，不随下一纪念日变化；到达第 100 天时隐藏倒计时并显示“可拆”，此后持续可读。服务端验证会话与解封日期，客户端日期仅负责公开状态显示。正文不进入静态 HTML、浏览器脚本或公开资源；关闭弹窗、退出、跨标签撤销会话时清空 DOM 与内存，并中止或忽略晚到请求。
- 额外值得标记的日子登记在 `src/data/moments.ts`（日期 + 标题），格子上显示一个圆点，点选时显示标题。只登记已确认的内容，目前有 2026-05-27“通过游戏认识”（早于日历首日，暂无格子）、2026-09-06“抖音火花 100 天”、2026-10-08“恋爱 100 天纪念”（与第 100 天心形重合，心形中加圆点，读数同时显示两者，按用户要求保留）。
- 静态 HTML 不写死构建当天的天数。无 JavaScript 时隐藏动态计数和统计，保留起始日期、完整的日历格子（全部未涂色）和图片原图链接。

## 视觉

- **颜色**（`src/styles/ui.css` 的 `:root` 与 `.dark`）：浅色纸面 `#f5eee4` 为默认，卡片 `#fffcf7`，墨色 `#2a1f1b`，辅助文字 `#76645b`；shadcn `--primary` 与 `--ring` 统一为蜡封红 `#b0474f`。页眉主题开关保存 `loveuhqq_theme=light|dark`，刷新后沿用；页面主题同步更新 `color-scheme` 与 `theme-color`，不跟随系统自动切换。纸面叠一层极淡的 SVG 噪点作纸纹。新增颜色一律进令牌，不在规则里写死。
- **衬纸**（`src/styles/global.css`）：照片章和封底共用 `--endpaper` / `--endpaper-ink`，浅色模式为深红 `#82383f` 与奶油白 `#fff4e9`，深色模式为 `#46252a` 与 `#efe7df`。用整块色面建立章节节奏，标题、说明、链接与焦点均保持可辨识的反差。
- **字体**：标题、数字、引文用思源宋体 400，正文和界面小字用系统无衬线字体，不请求任何外部字体服务。宋体以单个按站点用字生成的子集 woff2（约 73KB，`src/assets/fonts/`）随 CSS 分发并预加载，取代按 unicode-range 切片的整套字库。新增可见文案后必须运行 `npm run subset:font` 重新生成子集并提交；`tests/font-subset.test.mjs` 会在字符集不一致时让测试失败。
- **实物感**：胶带（半透明、锯齿边，米色或粉色）、拍立得白边、信纸横线与页边线、带墨色斑驳的邮戳（SVG 滤镜）、“待拆”／“可拆”橡皮章。阴影用多层柔和纸影；导航是吸顶半透明毛玻璃，滚动后背景加深，深色模式下保证文字对比。
- 纸心、信封是本地透明 WebP；信封素材预裁成显示比例（`envelope-620.webp`，800×620），不再靠 `object-fit` 裁切。所有图片声明固有尺寸，首屏纸心直接加载，其余懒加载。替换图片必须换新文件名（30 天 immutable 缓存）。

## 布局与响应式

- 主要内容宽度上限约 64–68rem，封面放宽至 74rem，两侧留白 `clamp(1.25rem, 5vw, 4rem)`，并尊重安全区。
- 封面桌面为横向跨页（左大题字、右纸心），中央以淡折痕暗示书脊，下方计数栏横跨两页；≤720px 时改为斜向构图，“爱你，”在左上，纸心在右侧，姓名在左下。邮戳收在页面内，计数栏左侧说明与日期、右侧数字。
- 日子桌面将标题和统计放在左栏，右侧并列年历与对应日记；纪念票根在两栏之后展开。日历格子保持 13 行 × 31 列，不为适配窄栏压小格子；≤1100px 回到单列，≤640px 年历转置为 13 列 × 31 行，月份名竖排在列顶。
- 照片章节铺深红衬纸，大标题与说明分列，以细线划分章头和照片。未解锁时三张待解锁拍立得并排，以实纸白边承托虚线空位；解锁后的照片桌面三列错落，手机第一张放大居中、其余两列。真实照片保持原始比例，过高的长截图在墙上从顶部截取（最高为卡片宽度的 1.5 倍），灯箱里显示全图；灯箱宽度按照片比例与可用高度计算。私密标题不进入公开宋体子集，因此拍立得标题和灯箱标题使用系统无衬线字体，可换行显示完整备注。
- 信纸、往后、回忆册入口和信件各自使用不同内容宽度与左右重心，沿页面交替展开；百日信突出红色数字 100。页脚以深红封底、大字号“往后。未完待续。”收束，操作入口排在细线下方。
- 页眉固定吸顶，始终使用半透明毛玻璃；滚动后背景稍加深并加细线。当前锚点或当前页以蜡封红高亮，桌面在离开封面后显示“第 N 天”小标签。手机保留字标和五个锚点链接，不做汉堡菜单。
- 首页 ≤720px 时字标及会话/主题在上行，五个导航等分占满下行；导航字至少 12px，点击区域至少 44px，`--header` 与两行实高一致，日历读数随之吸顶。

## 交互与动效

- **开场**：标题逐字“落墨”（由模糊到清晰），副题淡入，纸心轻轻落下，邮戳最后“盖”上去，天数从 0 数到今天。开场等门禁解锁、且宋体加载完成（最多等 1.5 秒）后才开始，避免标题中途换字体。
- 各区块首次进入视口时由 Motion 的 `inView` 淡入上移；日历由 Motion `animate` 依次涂色，整组总时长约 1 秒，与天数无关；信纸上的字从左到右“写”出来。
- 日历上方提供点选提示和日期读数，显示该日日期、第几天、距今还有几天（及周年名、故事标题）；手机上读数在页眉下随网格滚动停留。手机可以横向轻扫月份列预览日期，抬手后选中；纵向手势仍用于页面滚动，滚动中止轻扫预览并恢复之前的选中状态，不更改日记日期。悬停和轻扫仅临时预览（指针离开网格不改动正在看的年份），点选、轻扫抬手或方向键选择后保持读数并更新日记；点格子以外的地方或按 Esc 取消选择，读数回到当前显示年份的起止区间。选中日期后可从读数栏翻到下方的日记卡片。日历网格是一个键盘落点：方向键按可见排布移动（桌面左右逐日、上下约一个月；手机上下逐日、左右约一个月）、Home/End 跳到首末，读数同步更新。
- 纸心使用原生按钮，点击或聚焦后按 Enter / Space 会跳一下并飘出几颗小心；桌面指针在纸心上移动时轻微倾斜。文字链接在悬停或键盘聚焦时展开细下划线。未到日期时点信封会晃动并提示等待；日期已到且解锁后打开阅读弹窗。
- 门禁校验成功后先由 Motion 让邮戳落印并轻震，再让锁屏卡片淡出、整页从锁定状态展开；`prefers-reduced-motion` 下直接解锁。
- 拍立得悬停时摆正并抬起；点击打开原生 `dialog` 灯箱，支持左右方向键、手机左右滑动、Esc、关闭按钮和点遮罩关闭，关闭后焦点回到原来的照片。修饰键点击保留浏览器原图行为。
- 灯箱窄卡片的标题和照片序号分行；手机横屏按动态可用高度放大拍立得，切换按钮留在两侧，避免挤压图片和说明。
- 页内导航随滚动用小红点标出当前区块（`aria-current="location"`）。
- 年份切换按钮只在真的有别的年份可看时出现；切换后读数显示该年的起止日期并保持“回到今天”可用，方向键自动改用当年重建的格子。回看期间悬停、点空白处或按 Esc 都不改动正在看的年份，只有“回到今天”会跳回当前年份，并把年份按钮的可用状态一起刷新（回到第二年之后仍能再翻回第一年）。

## 门禁

- 全站共用。未解锁时整页被一张纸面遮住，问题用“我们，／是从哪天开始的？”分行呈现，提示“月和日，四位数字”。桌面门禁是一张带内框线的横向明信片，问题在左，邮戳与输入在右；手机回到单列，短横屏缩小边距和邮戳，空间不足时允许滚动。日期输入按 InputOTP 的月／日四格分组呈现，输满四位自动校验，也可按回车提交。“月和日”关联标签保留给辅助技术，视觉上由“月”“日”分组承担。锁屏上的邮戳不印起始日期（那正好是答案），只留 LOVEUHQQ 与“第一天”；首页的 `description`／`og:description` 同样不含起始日期，免得分享预览等于把答案递出去。
- 门禁脚本没能跑起来时（模块被拦、解析失败等），`<head>` 内联脚本会在 3 秒后解除普通初访锁定，避免整页永久空白；退出尚未确认时仍保持锁定。门禁一就绪就立刻标记 `gate-ready`。
- 日期输入校验逻辑与哈希不变（`src/lib/passphrase.ts`）。输错提示“好像不对，再想想。”并清空；输对后转入共同密码输入。密码阶段只显示输入框、解锁按钮与简短的“访客浏览”入口。只有服务器验证共同密码成功，才取得会话并读取私密记录；登录沿用原先默认的 30 天会话。
- 门禁提供访客浏览，进入公开页面后首页右上角显示可点击的“访客”，可以再次打开解锁界面；登录后显示“已解锁”和“退出”。退出成功才撤销服务器会话并切回访客，页脚和相册页“上锁”在退出后重新打开门禁。退出请求失败时清空已打开标签页的私密记录、同步保持门禁锁定、禁止访客浏览与 Esc 关闭，并提供重试；重新载入后仍保持锁定，直到服务器确认退出。门禁显示时其余页面 `inert`，关闭后恢复焦点。
- 日期问题是仪式感门槛，公开内容仍在 HTML 中；备注和清单由 Worker 真实认证保护，不写入静态 HTML。登录密码的验证值仅存 Worker secret，每个私密读写接口均验证会话，写操作校验同源。

## 可访问性与回退

- 封面标题整体带 `aria-label`，逐字的装饰 span 对辅助技术隐藏；装饰图、邮戳、胶带不参与读取。纸心按钮提供可读名称并保留键盘焦点。日历图例本身可读（色块、心形、圆点仍对辅助技术隐藏），不再是整块 `aria-hidden`。
- 减少动态效果偏好下关闭全部动画与过渡、平滑滚动；门禁不播放盖章或页面展开动画，直接解锁。开场内容直接可见，计数直接显示结果。
- 无 JavaScript 时不显示门禁，保留公开正文；百日信只展示信封图片与公开介绍，不显示拆信按钮，私密正文始终不在静态页面中。开场 CSS 动画照常播放。
- 焦点样式统一为蜡封红描边，所有可点目标不小于 44px（日历格子除外：整张网格是一个键盘落点，方向键翻看后由读数以文字播报该日信息）。网格整体聚焦时用内缩虚线标出、选中格另加蜡封红描边，避免给 366 个格子套一个满幅实线红框。

### 当前身份选择方式

共同门禁通过后，首页页眉显示当前署名（未选择时显示「选择身份」）；点击后展开一张小纸签，在「男生」「女生」之间选择或切换。选择成功后纸签收起，点击外部或按 Esc 也可关闭，焦点回到页眉入口。封面不放置身份切换条，也不为身份控制额外增加顶部留白。不再注册称呼或填写个人口令；选择会沿用到回忆册与共同桌面，可随时切换。两份署名段落、共同揭晓、未来信件的收件人与日期规则保留，已有记录不迁移、不删除。身份只区分署名，不提供双方之间的口令隔离；任何通过共同门禁的人都可以切换查看相应身份的内容。此前独立个人口令的描述由本约定替代。
