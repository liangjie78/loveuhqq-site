# 纸上手账

整站是一本摊开的手账：暖色纸面、蜡封红、宋体字，内容像是用胶带贴上去的实物——纸做的心、拍立得、信纸、信封和邮戳。目标是让它读起来像一个人亲手做的东西，而不是模板生成的落地页，所以刻意回避了渐变、毛玻璃、章节页码、侧边圆点导航和英文眉标这类常见套路。

本文件描述当前源码的设计约定，不代表生产网站已发布该版本；发布状态以部署记录和实际核验为准。

## 内容

- 只使用已确认的称呼、文案和日期：“爱你，何青青。”“记录生活，慢慢往前走。”“平平淡淡，踏实过好每一天。”“往后。未完待续。”，起始日 2026-07-01。界面上的说明性文字（按钮、提示、空状态）保持口语、克制，不写矫情情话，不编造经历、地点或私人信息。
- 首页自上而下：封面、日子、照片、心里话、往后、信、页脚。自然连续滚动，不分屏、不吸附。
- **封面**：竖排大标题“爱你，/ 何青青。”；左侧是贴着胶带的纸心，盖着写有起始日期的邮戳；下方是“今天，是我们在一起的 / 第 N 天”。
- **日子**：“一天，记一格。”每一天是一个格子，按月排成一行（手机上转为一月一列）。走过的日子涂上深浅不一的红，今天带一圈脉动描边，第 100 天和周年日是心形。下方统计“已经涂了 N 格”，随当前显示的年份变化；“下一个纪念日”倒计时始终从今天算起，是所有年份共用的一项“现在”。
- **回看往年**：日历默认显示今天所在的年份；进入第二年及以后，范围行下方出现“← 上一年 / 下一年 →”，可一直翻回第一年（第一年时整行收起），读数改成该年的起止日期，格子、“已经涂了 N 格”与 `aria-label` 一并切换，“回到今天”跳回当前年份。翻看往年不改动正在编辑的手账草稿。
- **照片**：三张拍立得，用胶带贴在纸上，微微倾斜；每张都标“示意图片”，说明文字写明真实照片待补。“翻开整本相册”进入 `/photos/`。
- **心里话**：一张横线信纸，左侧红色页边线和打孔，文字压在横线上。
- **信**：“写给第 100 天”。信封可以点，会晃一下并提示还没到拆的时候；旁边一枚“待写”印章和倒计时。第 100 天以前写“信还在写，等到 2026.10.08 那天再拆。”；那天过后换掉这句已经过期的日期说法，只留“信还在写。”。信的内容尚未提供，不自行撰写。
- **相册页**：全部照片以拍立得墙展示，末尾一个虚线空位“留给下一张”。
- **日子的背面**：日历下的一张折角纸签，随选择显示日期；主动点击“写一句”后才出现横线编辑器。记录保存在当前浏览器，支持修改、移除与撤销、按日期翻看；写过的格子带墨色描边。编辑期间保留正在写的日期，不因悬停或跨日切换草稿。
- **记下的日子**：以打孔票根展示已确认的故事日期和第一天，包括早于日历起点的记录。未来日期标注“还没到”；“保存这些日子为图片”将当前票根生成一张可直接打开的 PNG 图片，不创建系统提醒。
- **往后**：左侧留白与标题、右侧贴着胶带的横线清单；手机上下排列。内容初始为空，由用户填写，支持完成、移除与撤销，也可以从未完成事项里抽一件。
- 首页增加“往后”导航；≤380px 时字标与导航分两行，保持五个入口完整可点，日历置顶读数沿用对应页眉高度。
- 日记与清单共用本机手账备份，可导出 JSON 和恢复。恢复先完整校验再合并，同一天和同 ID 已有的记录优先，不覆盖当前内容。界面明确说明只留在这台设备、不会同步给对方；同源不同标签页更新会刷新显示，保存同一篇正在编辑的记录时检测冲突并保留输入。预览域名与正式域名的本机记录分别存放，需要通过备份迁移。无 JavaScript 时保留故事票根和清单空状态，隐藏编辑与下载按钮。
- **404**：一张底边被撕开的纸，“这一页，好像被撕掉了。”

## 日期与状态

起始日期的唯一来源是 `src/lib/anniversary.ts`。2026-07-01 为第 1 天，按北京时间日历日计数，在打开页面、跨午夜和回到前台时刷新。

- “恋爱年份”以周年日收尾：第一年从 2026-07-01 到 2027-07-01（共 366 格，末格是一周年），第二年从 2027-07-02 到 2028-07-01，以此类推。日子区块默认显示今天所在的年份，跨年后由脚本重建格子；跨年那一刻只把正在看当前年份的读者带去新年，正在回看旧年的人留在原处。
- 下一纪念日沿用原有规则：第 100 天之前指向第 100 天，之后指向最近的周年日，当天显示“就是今天”。
- 信固定为第 100 天主题，不随下一纪念日变化；过了第 100 天倒计时隐藏、信里那句日期说法一并隐去（只留“信还在写。”），“待写”印章保留，点信封提示“信还在写。”
- 额外值得标记的日子登记在 `src/data/moments.ts`（日期 + 标题），格子上显示一个圆点，点选时显示标题。只登记已确认的内容，目前有 2026-05-27“通过游戏认识”（早于日历首日，暂无格子）、2026-09-06“抖音火花 100 天”、2026-10-08“恋爱 100 天纪念”（与第 100 天心形重合，心形中加圆点，读数同时显示两者，按用户要求保留）。
- 静态 HTML 不写死构建当天的天数。无 JavaScript 时隐藏动态计数和统计，保留起始日期、完整的日历格子（全部未涂色）和图片原图链接。

## 视觉

- **颜色**（`src/styles/global.css` 的 `:root`）：纸面 `#f5eee4`，贴纸/卡片 `#fffcf7`，墨色 `#2a1f1b`，辅助文字 `#76645b`，蜡封红 `#b0474f` 及浅红、深红、日历三档手涂红等派生；墨色透明度仅保留 `--line`/`--line-strong`/`--line-stronger` 三档。固定浅色，系统深色偏好不改变配色。纸面叠一层极淡的 SVG 噪点作纸纹。新增颜色一律进 `:root` 令牌，不在规则里写死。
- **字体**：标题、数字、引文用思源宋体 400，正文和界面小字用系统无衬线字体，不请求任何外部字体服务。宋体以单个按站点用字生成的子集 woff2（约 73KB，`src/assets/fonts/`）随 CSS 分发并预加载，取代按 unicode-range 切片的整套字库。新增可见文案后必须运行 `npm run subset:font` 重新生成子集并提交；`tests/font-subset.test.mjs` 会在字符集不一致时让测试失败。
- **实物感**：胶带（半透明、锯齿边，米色或粉色）、拍立得白边、信纸横线与页边线、带墨色斑驳的邮戳（SVG 滤镜）、“待写”橡皮章、蜡封按钮。阴影用多层柔和纸影，不用大面积模糊。
- 纸心、信封是本地透明 WebP；信封素材预裁成显示比例（`envelope-620.webp`，800×620），不再靠 `object-fit` 裁切。所有图片声明固有尺寸，首屏纸心直接加载，其余懒加载。替换图片必须换新文件名（30 天 immutable 缓存）。

## 布局与响应式

- 内容宽度上限约 64–68rem，两侧留白 `clamp(1.25rem, 5vw, 4rem)`，并尊重安全区。
- 封面桌面为左右两栏（左纸心与计数，右竖排标题）；≤720px 时纸心与竖排标题并排、计数移到下方整行。
- 日历格子桌面为 13 行 × 31 列；≤640px 时转置为 13 列 × 31 行，月份名竖排在列顶，格子更大，便于手指点选。
- 照片桌面三列错落；手机第一张放大居中，其余两列。拍立得用容器查询，窄卡片的标题与“示意图片”标签上下排列，避免截断。
- 页眉固定，顶部透明，滚动后变为纸色并加细线；桌面在离开封面后显示“第 N 天”小标签。手机保留字标和五个锚点链接，不做汉堡菜单。
- ≤380px 时字标与五个导航分两行，链接保持至少 44px 的点击区域。

## 交互与动效

- **开场**：标题逐字“落墨”（由模糊到清晰），副题淡入，纸心轻轻落下，邮戳最后“盖”上去，天数从 0 数到今天。开场等门禁解锁、且宋体加载完成（最多等 1.5 秒）后才开始，避免标题中途换字体。
- 各区块首次进入视口时淡入上移；日历进入视口时，走过的格子按顺序依次涂色（总时长约 1 秒，与天数无关）；信纸上的字从左到右“写”出来。
- 日历上方提供点选提示和日期读数，显示该日日期、第几天、距今还有几天（及周年名、故事标题）；手机上读数在页眉下随网格滚动停留。悬停仅临时预览（指针离开网格不改动正在看的年份），点选或方向键选择后保持读数；点格子以外的地方或按 Esc 取消选择，读数回到当前显示年份的起止区间。日历网格是一个键盘落点：方向键按可见排布移动（桌面左右逐日、上下约一个月；手机上下逐日、左右约一个月）、Home/End 跳到首末，读数同步更新。
- 点纸心会跳一下并飘出几颗小心；桌面指针在纸心上移动时轻微倾斜。点信封会晃动并弹出提示。
- 拍立得悬停时摆正并抬起；点击打开原生 `dialog` 灯箱，支持左右方向键、手机左右滑动、Esc、关闭按钮和点遮罩关闭，关闭后焦点回到原来的照片。修饰键点击保留浏览器原图行为。
- 灯箱窄卡片的标题和照片序号分行；手机横屏按动态可用高度放大拍立得，切换按钮留在两侧，避免挤压图片和说明。
- 页内导航随滚动用小红点标出当前区块（`aria-current="location"`）。
- 年份切换按钮只在真的有别的年份可看时出现；切换后读数显示该年的起止日期并保持“回到今天”可用，方向键自动改用当年重建的格子。回看期间悬停、点空白处或按 Esc 都不改动正在看的年份，只有“回到今天”会跳回当前年份，并把年份按钮的可用状态一起刷新（回到第二年之后仍能再翻回第一年）。

## 门禁

- 全站共用。未解锁时整页被一张纸面遮住（不再是毛玻璃模糊），问题是“我们，是从哪天开始的？”，提示“月和日，四位数字”。四个日期格镜像一个隐藏的数字输入框，输满四位自动校验，也可按回车或点蜡封“开”按钮提交。锁屏上的邮戳不印起始日期（那正好是答案），只留 LOVEUHQQ 与“第一天”；首页的 `description`／`og:description` 同样不含起始日期，免得分享预览等于把答案递出去。
- 门禁脚本没能跑起来时（模块被拦、解析失败等），`<head>` 内联脚本会在 3 秒后解除锁定，避免整页永久空白；门禁一就绪就立刻标记 `gate-ready`，真实锁定不受这条保险丝影响。
- 输错时日期格抖动、提示“好像不对，再想想。”并清空；输对后纸面淡出、开场动画开始。校验逻辑与哈希不变（`src/lib/passphrase.ts`），“记住这台设备”默认勾选。
- 锁定期间页面其余部分设为 `inert` 并隐藏，焦点只在门禁内。页脚和相册页提供“上锁”。
- 这是一道软门槛，内容仍在 HTML 中，不承担真正的访问控制。

## 可访问性与回退

- 竖排标题整体带 `aria-label`，逐字的装饰 span 对辅助技术隐藏；装饰图、邮戳、胶带不参与读取。日历图例本身可读（色块、心形、圆点仍对辅助技术隐藏），不再是整块 `aria-hidden`。
- 减少动态效果偏好下关闭全部动画与过渡、平滑滚动，开场内容直接可见，计数直接显示结果。
- 无 JavaScript 时不显示门禁、不隐藏任何正文；开场 CSS 动画照常播放。
- 焦点样式统一为蜡封红描边，所有可点目标不小于 44px（日历格子除外：整张网格是一个键盘落点，方向键翻看后由读数以文字播报该日信息）。网格整体聚焦时用内缩虚线标出、选中格另加蜡封红描边，避免给 366 个格子套一个满幅实线红框。

## 修改位置

- `src/pages/index.astro`、`src/pages/photos.astro`、`src/pages/404.astro`：页面结构；两页的拍立得卡片由 `src/components/PolaroidCard.astro` 共用。
- `src/layouts/Page.astro`：共用的 head、门禁预判脚本、字体子集预载与加载等待。
- `src/components/`：`SiteHeader`（页眉）、`Postmark`（邮戳 SVG）、`PassphraseGate`（门禁）、`Lightbox`（灯箱）、`PolaroidCard`（拍立得）。
- `src/styles/global.css`：全部样式与动效，颜色集中在 `:root` 令牌。
- `src/scripts/journal.ts`：首页日期、日历（含键盘翻看）、计数、页眉状态、纸心与信封；`gallery.ts`：灯箱；`reveal.ts`：滚动淡入；`passphrase-gate.ts`：门禁。
- `src/lib/anniversary.ts`（含恋爱年份、按月日历与共享的日期格式、月份名）、`tests/anniversary.test.mjs`、`tests/calendar.test.mjs`：日期计算与测试。
- `src/data/photos.ts`、`src/data/moments.ts`、`public/images/`：照片、值得标记的日子与本地素材。
- `src/components/Notebook.astro`、`FutureList.astro`、`MomentArchive.astro`、`src/styles/notebook.css`：新增纸签、清单与故事票根；`src/scripts/notebook.ts` 负责本机记录，`src/lib/notebook.ts` 负责备份校验与合并，`src/lib/moment-image.ts` 生成可打开的纪念日图片。
- `scripts/subset-font.mjs`、`src/assets/fonts/`、`tests/font-subset.test.mjs`：宋体子集的生成、产物与字符集守卫；`astro.config.mjs` 禁止字体内联（CSP 只允许同源字体）。
- `wrangler.jsonc`、`wrangler.preview.jsonc`：静态资源目录，以及 `not_found_handling: "404-page"`——没有这一项时 Workers 静态资源只回一个空 404 正文，`dist/404.html` 不会送到访客手里。

验收需实际构建，并用真实浏览器检查桌面与手机视口的封面、日历横竖两种排布、往年回看、照片与灯箱、信纸、信封提示、门禁输错/输对、跨日显示、无脚本回退和减少动态效果偏好；404 与 `not_found_handling` 必须在 Workers 运行时（本地 `wrangler dev` 或预览 Worker）核验正文，只看到 404 状态码不算通过。单元测试不能替代视觉与输入验收；验证结果单独记录，不由本设计约定推定通过。
