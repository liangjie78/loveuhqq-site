# 余温 · 视觉自评记录

对照 Awwwards / Webby / FWA 获奖作品的常见特征，逐维度检查重建后的站点。截图来自本地 Worker + 生产构建 + 本地示例数据（`docs/previews/yuwen-*.webp`），桌面 1440×900、平板 768×1024、手机 390×844，浅色与深色。

这是作者自评，不是评委结论；动效部分无法在静态截图中完整体现，以浏览器实际观感为准。

## 第一轮发现与修补

| 维度 | 发现的差距 | 处理 |
| --- | --- | --- |
| 排版 | 「往后的日子也想和你一起」「共同回忆册」「写给第 100 天」桌面窄栏里末字单独成行 | 标题改为按视口封顶的字号并禁止断行 |
| 排版 | 手机上「慢慢往前走。」「未完待续。」句号掉行；封面「爱你，」逗号压到「何」 | 字号按 vw 封顶、行高 1.1、第二行缩进加大 |
| 排版 | 段落末尾孤字（“都涂/上了颜色”“再/写。”） | 全站正文 `text-wrap: pretty`，标题 `balance` |
| 留白 | 子页页眉在手机上挤成两行 | 窄屏隐藏会话说明，“回到日记”只留图标（保留读屏名称） |
| 视觉层级 | 回忆册页目录没有样式（样式只在首页加载） | 目录样式随组件加载 |
| 视觉层级 | 信的“待拆”印压在标题上 | 移到信封右上角，像邮戳 |
| 颜色 | 页眉滚动后底下文字透出 | 页眉背景改为毛玻璃 + 渐隐遮罩，压在夜幕章节上自动换色 |
| 动效 | 滚轮数字被父级压成一行、裁切露出下一位 | 列高固定、只做纵向裁切 |
| 动效 | 灯箱放大动画结束停在 `scale(0)`（Motion 把 `none` 插值成全零） | 改用 WAAPI 并给出显式终点；其余同类写法全部替换 |
| 动效 | 信件正文淡入后不可见 | 去掉与关键帧冲突的初始不透明度 |
| 微交互 | 门禁密码阶段长标题顶到右边缘 | 标题字号按 vw 封顶 |
| 响应式 / 无障碍 | 减少动态效果时封面字仍停在动画延迟中（只清了 transition-delay） | 一并清零 animation-delay；由端到端测试覆盖 |

## 第二轮复查

修补后重新截取全部页面与状态，并跑通 `npm test`（73 项）、`npm run test:build`（9 项）、`npm run test:e2e`（桌面 + 手机 29 项）。

| 维度 | 结论 | 依据 |
| --- | --- | --- |
| 排版 | 无明显改进空间 | 超大可变字重宋体 + 意大利体数字的双字体系统；九级流体字号；无孤字、无溢出（端到端测试检查横向滚动） |
| 留白 | 无明显改进空间 | 12 栏网格、章节 20vh 级留白、左右重心交替；手机 16px 以上侧边距 |
| 视觉层级 | 无明显改进空间 | 每章统一“序号 · 章名 · 说明”，主次三级清晰；夜幕章节制造明暗节奏 |
| 颜色 | 无明显改进空间 | 单一强调色、光晕只作光；正文对比度全部 ≥ AA；深色「夜灯」独立调色而非反色 |
| 动态效果 | 无明显改进空间 | 光晕、显影、串灯、逐字点亮、光绽、拆信、灯箱放大、视图转场；全部可被减少动态效果关闭 |
| 微交互 | 无明显改进空间 | 墨池按钮、磁吸、主题圆形铺开、导航指示器滑动、勾选画线、抽一件洗牌、心形余烬、鱼眼日历 |
| 响应式设计 | 无明显改进空间 | 手机全屏菜单、竖排年历、平衡分栏相册、灯箱底部翻页；390 / 768 / 1440 三档截图核对 |
| 原创性 | 无明显改进空间 | “余温”概念贯穿：光晕随相处天数变亮、每天一粒光、读到的字才亮、门禁以光打开 |

## 已知限制

- 可变字重宋体子集约 196KB（比固定字重大约 80KB），换来字重呼吸效果；字体预载并以 `swap` 显示。
- 动效评估依赖人工观感；自动测试只能覆盖“减少动态效果下内容直接可见”等可判定的部分。
- 照片、故事等示例内容来自本地测试数据，正式效果取决于真实照片。
