# 需求定稿：解锁后可在照片墙添加照片

> 状态：**定稿 v1.0** · 2026-10-11（Asia/Shanghai）  
> 仓库：`/workspace/loveuhqq-site`  
> 产品：Hannah Cole  
> 依据：总助只读摸底（session Cookie、GET `/api/photos`、CLI→KV、装饰空位、PHOTOS KV / `photos.ts`、DESIGN「留给下一张」）

---

## 1. 问题

私密相册只能本机 `photos:prepare` + Wrangler 写入 Workers KV，**站内不能上传**。Worker 照片路径目前仅允许 `GET`；未登录 401。

解锁后相册页末尾「留给下一张」是 `gallery.ts` 的装饰空位（`emptySlot`），无交互。两人想加一张新照片必须找能跑 CLI 的人，和共同手账可在线编辑不一致。

**目标**：在日期口令 + 共同手账密码换得的**服务端 session（Cookie）**有效时，可在站点内添加照片，并立刻出现在相册墙。

---

## 2. 用户

| 角色 | 谁 | 能做什么 |
| --- | --- | --- |
| 共同主人 | 完成门禁并持有有效 session 的两人 | 看相册、**添加**照片 |
| 访客 | 未解锁 / 无 session | 只看「待解锁」空位；不能读图、不能传 |
| 运维 | 有仓库与 Wrangler 权限的人 | 继续用 CLI 做批量/纠错；不替代站内添加主路径 |

---

## 3. 方案

### 3.1 产品决策（已定）

| 议题 | 定稿 |
| --- | --- |
| 谁可上传 | **仅持有有效服务端 session 的解锁用户**；访客与无 Cookie 会话一律不可 |
| 是否改 featured | **本期不改**：新图不自动进首页三张；不提供站内改精选 UI；精选仍靠现有 manifest `featured` / CLI |
| 是否删图 | **本期不做删图**（含批量删）；删除仍走运维/CLI。后续可单独立项 |
| 添加入口 | **仅相册页** `/photos/`：把「留给下一张」升级为可点入口；首页精选墙不放添加 |
| 单次数量 | **一次一张**（实现简单、易验收）；连选多张不在本期 |
| 文案 | 可点空位沿用/贴近「留给下一张」；操作短句用「贴一张」；失败：「这张暂时贴不上，再试一次。」 |

### 3.2 主流程

1. 已解锁用户打开 `/photos/` → 墙末可点空位「留给下一张」/「贴一张」。
2. 选本地图片 → 标题（默认文件名去扩展名，必填，≤80 字）→ 拍摄日期可选（有则用于排序与角标）。
3. 客户端生成去 EXIF/GPS 的 WebP：`thumb` + `large`（对齐现 `photos:prepare`：大图最长边约 ≤1800、缩略约 800×1000 内）。
4. 经鉴权写接口写入 `PHOTOS` KV，更新 `manifest.json`（格式仍为 `src/lib/photos.ts`）。
5. 成功后刷新相册墙与「N 张我们的照片。」；可点灯箱。失败可重试，不留下导致整本相册 503 的坏清单。
6. 退出 / 跨标签撤销 session：立即清空私密 DOM、恢复锁定空位、隐藏添加入口；进行中上传中止或忽略晚到响应。

### 3.3 鉴权与存储（与摸底对齐）

- 解锁链路：日期口令 + 共同密码 → **Cookie session**（不是 localStorage 当真登录）。
- 读：现有 `GET /api/photos`、`GET /api/photos/:id/:size`；无 session → 401。
- 写：新增需 session + 同源校验的上传接口（当前照片路径仅 GET，须扩展；未登录写 → 401）。
- 存储：现有 Workers KV `PHOTOS`；清单上限约 **2000** 张；单值 **≤25MB**。预览与生产命名空间隔离；**禁止用生产真实私人照片做公开预览验收**。
- CLI 上传保留，与站内上传共用同一清单模型。

## 5. 验收标准（可验收范围）

### A. 权限

1. 无 session：无添加入口；照片写接口 401（或等价拒绝）；读仍 401。
2. 有 session：相册页有添加入口；可完成单张上传。

### B. 添加成功

3. 上传成功后新拍立得出现在 `/photos/` 墙中；摘要张数 +1。
4. 标题显示正确；有日期则角标与排序符合现规则（无日期靠后）。
5. 首页精选三张**不因本次上传而自动变化**。

### C. 安全与会话

6. 公开 HTML / 构建产物仍不含私密图字节与私密标题；读图缓存策略不弱于现状（`private, no-store` 等）。
7. 退出或跨标签撤销后：墙恢复空位、添加入口消失、无残留私密图；半途上传不写坏整本清单。

### D. 失败与回归

8. 网络/服务错误有明确文案与重试。
9. 灯箱、首页精选只读展示、CLI 上传路径、共同手账备注/清单回归通过。
10. 预览环境只用测试图验收；生产写入与正式发布须用户明确同意后再做。

### E. 限额（工程实现约束）

11. 单张写入遵守 KV 单值 ≤25MB；客户端先压到约定尺寸，避免打满限额。
12. 清单照片数不超过现模型上限（约 2000）；接近上限时有可读失败提示（文案工程可草案，产品可再润色）。
